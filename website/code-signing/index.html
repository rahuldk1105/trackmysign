Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed
The Windows installer (TrackMySign-Setup-windows-x64.exe), the application executable inside it, and the command-line tool (trackmysign-windows-x64.exe) published on the GitHub releases page.
How binaries are built
Every release is built by GitHub Actions directly from the public source in github.com/rahuldk1105/trackmysign. No binary is built or signed on a personal machine.
Committers and reviewers
DK Rahul (@rahuldk1105)
Approvers
DK Rahul (@rahuldk1105), repository owner. Every signing request is approved manually.
Privacy policy
This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. TrackMySign signs PDFs locally with the user's DSC token; documents, certificates and PINs never leave the computer, and the app has no analytics or telemetry.
Third-party components
The app talks only to the token driver (PKCS#11 library) installed by the token's vendor, on the same computer. It bundles open-source libraries (Tauri, PDF.js, RustCrypto) that make no network requests in this app.
Reporting problems
Report a suspicious or incorrectly signed binary by opening an issue at github.com/rahuldk1105/trackmysign/issues.
